Awareness & record

Everything that happened, verbatim, forever.

Witness is the append-only record at the bottom of the stack. Every session, agent dispatch, hook fire, MCP call, and cron run produces events — Witness captures them verbatim, attributed to their source, and never merges them. When you later ask "what led to this?", Witness can answer with a chain, not a shrug.

The problem it solves

"What led to this signal?" shouldn't end in five different log formats.

A rich coherence stack produces signals, intents, decisions, and critiques — but the raw substrate those conclusions were drawn from fragments across tools, sessions, and agents, each in its own format. Today's signal says "Brien noticed X" but can't cite the discrete events that produced it. Witness closes that gap: one uniform event shape across every surface, one trace model connecting them, one lineage path from the raw moment back to every derived conclusion built on top of it.

A signal without a lineage is a belief. A signal with a lineage is evidence.
How it works

Capture once. Promote upward. Never destroy.

1

Events arrive

Sessions, agents, cron jobs, hooks, MCP backends, and external fetches all emit events. Witness ingests via OTLP spans or structured JSONL — each tagged with its source system so provenance is never ambiguous.

2

Events are stored verbatim

Every event lands append-only in the event store, exactly as emitted, with its source attribution intact. Two contradictory claims from two agents produce two events — never a reconciled third event that erases the contradiction.

3

Events promote to signals

When a pattern is worth surfacing, events are promoted to signals with preserved lineage — the raw events remain; the signal carries a caused_by pointer. The signal layer reads up; the record layer never changes.

What makes it different

The conservation law: raw events are never destroyed.

The rule the whole product is built around

Aggregation at capture time is a conservation violation.

Most observability tools merge, summarize, or deduplicate on ingest. Witness refuses. Every event is preserved verbatim, exactly as its source emitted it. Two agents producing contradictory claims produce two events — the contradiction is the information, not noise to be resolved. Aggregation is always a downstream derivation: Track 2 can promote events to signals, and signals can summarize, but the raw record is never touched. The output at the capture layer is always two channels that are never merged:

Raw events

Every discrete moment captured, stored append-only, attributed to source — the substrate every higher layer is built on.

Promoted signals

Patterns worth acting on, elevated by Track 2 with a lineage pointer back to the raw events that produced them. The original events remain.
